The declared QoS history depth reaches the compiler again: a contract's `qos: { depth: N }` on a subscriber endpoint is rendered per component and `NROS_SUBSCRIBE` static_asserts each call site against it, so a code/contract disagreement fails the BUILD. `nano_ros_node_register()` claims the include dir and a deferred render after `nano_ros_entry()` fills it, which is what lets a model-driven producer replace the retired `ENTITIES` without an extra configure pass. The table is keyed on the TOPIC a call site writes rather than on the endpoint ref the contract addresses it by, and a contract stating `depth: 0` is refused rather than rendered.
